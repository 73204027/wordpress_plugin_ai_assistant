### SKILL
A skill is:
the capability to reliably perform a task under constraints.

Knowledge ≠ Intelligence ≠ Skills

In AI engineering, “skills” emerge from:

abstraction
repetition
pattern compression
feedback loops
tool usage
domain understanding

At the deepest level:
Input
 → Processing
   → Decision
     → Action
       → Feedback

**Primitive Skills:** Fundamental operations
*Examples:*
* reading code
* parsing JSON
* writing SQL
* debugging syntax
* HTTP requests
* Git usage
These are like CPU instructions.

**Composite Skills:** Combination of Primitive Skills
*Examples:*
* building REST APIs
* implementing authentication
* creating RAG pipelines
* Docker deployment
* React state management

These are like software functions.

**System Skills:** Managing interacting components
*Examples:*
* building REST APIs
* implementing authentication
* creating RAG pipelines
* Docker deployment
* React state management

**Meta Skills:** Meta (Skills about getting skills)
*Example:*
* learning rapidly
* abstraction
* debugging thinking
* decomposition
* prioritization
* communication
* research ability
